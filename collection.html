构建高可用系统的 7 个关键原则

 文章

现代前端架构的演进路径

↗

来源：Martin Fowler · 2023

从单页应用到微前端与模块联邦的思考。

 Skill

先定架构再写代码

↗

Cursor pstack · 工作技能 · architect

用于跨函数、模块的复杂改动。先研究现有系统，并行比较类型、接口和模块草图，再综合方案实现；反复受阻时重新设计。

 Skill

多案竞选择优融合

↗

Cursor pstack · 工作技能 · arena

用于一个方案可能过早定型的任务。让多个候选独立完成同一题目，按标准评分并交叉评审，选出底稿、吸收其他方案优点并验证。

 Skill

提炼个人工作模式

↗

Cursor pstack · 工作技能 · automate-me

用于把自己的工作习惯变成代理可遵循的模式。结合当前工作区近期对话和本人反馈，创建或更新个人 -mode 技能。

 Skill

核验性能测量结论

↗

Cursor pstack · 工作技能 · benchmark-checklist

用于运行基准或报告实测提速、回退。检查瓶颈、配置、错误、工作是否真正执行及重复性，避免拿失真的数字做决策。

 Skill

追查改动外溢风险

↗

Cursor pstack · 工作技能 · blast-radius

用于判断小改动可能破坏哪些周边行为。追踪跨库、时序和数据格式影响，找出安全所依赖的关键事实，并用真实代码验证。

 Skill

把上条回复说人话

↗

Cursor pstack · 工作技能 · bro

用于上一条回复术语太多或难懂时。用简洁、自然的日常语言重新表述同一内容。

 Skill

从结构上杜绝惯犯

↗

Cursor pstack · 工作技能 · correct

用于代理在同一仓库反复犯相同错误。归纳重复失误，优先用架构和类型消除，再用检查或测试约束，并证明能拦住旧错误。

 Skill

创建形式验证技能

↗

Cursor pstack · 工作技能 · create-formal-verification-skill

用于并发、重试、不变量等测试难覆盖的高风险逻辑。选择合适验证工具，验证关键性质，并留下可重跑、注明范围和代码对应关系的项目技能。

 Skill

创建真实应用验证

↗

Cursor pstack · 工作技能 · create-verification-skill

用于项目缺少可脚本化的行为证明方式。根据仓库生成启动、健康检查、操作、取证和清理流程，以及用户功能地图，并跑通一次。

 Skill

为复杂任务定流程

↗

Cursor pstack · 工作技能 · figure-it-out

用于没有现成流程可套用的大型迁移或多部分任务。先明确完成判据和风险，再设计可审计步骤，逐项实验验证并记录决策。

 Skill

读懂系统如何运转

↗

Cursor pstack · 工作技能 · how

用于代码走读、理解子系统或判断功能应放在哪层。按复杂度安排探索与综合，说明核心概念、运行流程、模块归属和注意点。

 Skill

复述目标确认理解

↗

Cursor pstack · 工作技能 · in-your-own-words

用于检查代理是否理解了需求。用自己的话说明用户想达到什么目标、正在解决什么问题。

 Skill

多方对抗实证评审

↗

Cursor pstack · 工作技能 · interrogate

用于挑战代码、改动或设计的盲点。让多个评审尝试破坏目标，仅保留实际运行可重现的问题，报告发现而不直接修复。

 Skill

用短视频补齐进展

↗

Cursor pstack · 工作技能 · ketchup-video

用于希望快速看懂本轮对话进展时。把已有事实和产物整理成带字幕的简短视频，并在视频下列出需要本人决定的事项。

 Skill

补齐本轮工作进展

↗

Cursor pstack · 工作技能 · ketchup

用于离开一会儿后了解本次对话发生了什么。只读核查进展，以简明文字和已有图像说明变化，并列全需要本人决定的事项。

 Skill

同步维护形式验证

↗

Cursor pstack · 工作技能 · maintain-formal-verification-skill

用于被验证代码变化后检查模型是否过时。追溯覆盖代码的提交，更新验证而不改产品代码，重跑并区分模型漂移与真实缺陷。

 Skill

维护应用验证地图

↗

Cursor pstack · 工作技能 · maintain-verification-skill

用于审计已有验证技能及功能地图。并行核对功能源码，再由协调者逐项实测，只提交有证据支持的文档、地图或操作脚本修正。

 Skill

制作机器人操作页

↗

Cursor pstack · 工作技能 · make-bot-ui

用于制作按钮可唤醒 Grok Bot 的网页或仪表盘。由服务端向 webhook 例程发送请求，密钥留在服务端，并可通过 Tailscale 提供访问。

 Skill

清理注释修正根因

↗

Cursor pstack · 工作技能 · no-comments

用于审查改动中的注释与抑制指令。调用专门评审，清理应删除的内容并修复相关根因；对约束考虑改成类型、测试或检查。

 Skill

查询工作流与用法

↗

Cursor pstack · 工作技能 · poteto-help

用于了解 pstack 设置、技能选择和运行问题。依据对应源文档回答，给出一个可发送的提示词和公开链接，不把咨询直接当成执行请求。

 Skill

统筹严谨开发流程

↗

Cursor pstack · 工作技能 · poteto-mode

用于采用 poteto 的代理工作风格。按任务选择调查、开发、排错、交付等流程，协调子代理与其他技能，并要求真实验证和简洁汇报。

 Skill

连败先验证共同前提

↗

Cursor pstack · 工程原则 · principle-attack-the-premise

用于多个修复都基于同一假设且连续失败时。先写明并直接测试共同前提，再沿证据找原因，避免继续给错误假设打补丁。

 Skill

边界校验内部纯净

↗

Cursor pstack · 工程原则 · principle-boundary-discipline

用于安排校验、错误处理和框架适配。把原始数据检查集中在系统边界，内部信任类型，业务逻辑尽量使用纯函数。

 Skill

先造可重跑的工具

↗

Cursor pstack · 工程原则 · principle-build-the-lever

用于非平凡的编辑、迁移、分析或检查。先建立完成或证明任务的最小脚本、生成器或统一操作规范，让结果可以复现和复核。

 Skill

把重复教训固化约束

↗

Cursor pstack · 工程原则 · principle-encode-lessons-in-structure

用于同一指令或纠正第二次出现时。优先把规则编码成 lint、元数据、运行时检查或脚本；无法编码的判断才强化文字与反例。

 Skill

多种原型并排比较

↗

Cursor pstack · 工程原则 · principle-exhaust-the-design-space

用于缺少先例的交互、产品体验或架构选择。先做两到三个相互竞争的原型并比较，再决定采用哪一种。

 Skill

用户体验优先取舍

↗

Cursor pstack · 工程原则 · principle-experience-first

用于产品、交互和功能范围的权衡。优先打磨核心体验，宁可少做而做精，同时考虑使用者和后续维护者的负担。

 Skill

先解释数字再下结论

↗

Cursor pstack · 工程原则 · principle-explain-the-number

用于测量或使用性能、吞吐、延迟及评测数字。先明确什么结果会改变决策，再找瓶颈，排除噪声、错误和未执行工作，并保留证据。

 Skill

追到源头修复故障

↗

Cursor pstack · 工程原则 · principle-fix-root-causes

用于调试与排错。先复现并追到最早错误决策，区分合法异常状态与不该出现的状态，修复根因而不是靠守卫或重试掩盖症状。

 Skill

先定数据再铺基础

↗

Cursor pstack · 工程原则 · principle-foundational-thinking

用于写逻辑前选择核心类型、数据结构和工作顺序。先减负，再建立共享基础与测试；并发场景先判断是否应隔离状态。

 Skill

控制上下文信息负担

↗

Cursor pstack · 工程原则 · principle-guard-the-context-window

用于大输出、长文件或并行规划挤占上下文时。把批量阅读交给子代理，主线程保留摘要，并限制阶段范围与预算。

 Skill

以最小改动解决问题

↗

Cursor pstack · 工程原则 · principle-laziness-protocol

用于重构、衡量改动规模或考虑增加抽象时。优先删除与简化，把重复决策收敛到单一来源，避免无必要的层和模板代码。

 Skill

让重复执行安全收敛

↗

Cursor pstack · 工程原则 · principle-make-operations-idempotent

用于可能崩溃、重启或重试的命令和处理循环。根据当前状态只补齐与目标的差异，并让遗留半成品可识别、可恢复。

 Skill

迁移调用后删除旧接口

↗

Cursor pstack · 工程原则 · principle-migrate-callers-then-delete-legacy-apis

用于无需对外兼容的内部接口改造。一次协调迁移调用方、更新新契约测试并删除旧接口，避免留下临时兼容层。

 Skill

减少阅读跳转与隐态

↗

Cursor pstack · 工程原则 · principle-minimize-reader-load

用于代码难追踪或层次过多时。合并价值不足的包装层，缩小可变状态范围，让读者容易看清数据来源与修改者。

 Skill

用结构表达领域规则

↗

Cursor pstack · 工程原则 · principle-model-the-domain

用于有状态逻辑、分支膨胀或多处重复数据假设时。选择状态机、类型模型、注册表等合适结构，集中规则并减少非法状态。

 Skill

可逆工作先做再汇报

↗

Cursor pstack · 工程原则 · principle-never-block-on-the-human

用于可逆执行细节不值得等待本人确认时。作出合理选择后展示结果，让人异步纠偏；不可逆操作仍需确认。

 Skill

围绕最终状态推进迁移

↗

Cursor pstack · 工程原则 · principle-outcome-oriented-execution

用于有明确阶段边界的重写或迁移。以目标架构为准，允许计划内、可逆的中间破坏，避免为过渡状态堆兼容代码，并在终点完整验证。

 Skill

核查真实产物再报完成

↗

Cursor pstack · 工程原则 · principle-prove-it-works

用于任务完成前判断结果是否可信。直接运行功能、读取实际值或检查真实差异，能脚本化就留下可重复执行的验证。

 Skill

把新需求纳入整体设计

↗

Cursor pstack · 工程原则 · principle-redesign-from-first-principles

用于向已有系统加入新要求。假设该要求从第一天就存在，重新考虑整体结构，更新所有引用，再分步交付而非局部拼接。

 Skill

先隔离共享写入目标

↗

Cursor pstack · 工程原则 · principle-separate-before-serializing-shared-state

用于多个并发执行者可能写同一文件、分支或对象时。优先分配独立所有权，只有共享确属必要时才用锁、单写者或原子操作串行化。

 Skill

拆成逐步可验证单元

↗

Cursor pstack · 工程原则 · principle-sequence-verifiable-units

用于批量修改、迁移和提交堆叠。每个小单元都从已知良好状态开始，改完即验证，再按能证明前后因果的顺序交付。

 Skill

先删冗余再增加能力

↗

Cursor pstack · 工程原则 · principle-subtract-before-you-add

用于安排新增、重构或重写顺序。先移除死代码、重复校验和无内容引用，再在更简单的基础上建设，避免为猜测场景预留复杂性。

 Skill

测试可观察行为契约

↗

Cursor pstack · 工程原则 · principle-test-behavior-not-implementation

用于新增、修改或保留测试时。通过用户或调用方使用的接口断言结果和外部影响，使测试能抓住行为破坏又能承受内部重构。

 Skill

用类型排除非法状态

↗

Cursor pstack · 工程原则 · principle-type-system-discipline

用于静态类型设计和函数签名评审。区分语义不同的基础值，在边界解析外部数据，并从权威 schema 派生类型，让编译器阻止不合法组合。

 Skill

找回跨会话工作上下文

↗

Cursor pstack · 工作技能 · recall

用于开始或恢复某个主题的近期工作。结合限定工作区的历史对话、共享记录和当前状态，整理决策、未完成线程、反复问题及下一步。

 Skill

复盘会话沉淀技能改进

↗

Cursor pstack · 工作技能 · reflect

用于从刚完成的工作提炼长期经验。并行评审判断、工具和其他视角，综合为具体技能修改建议；获明确批准后才应用接受的改动。

 Skill

配置角色模型与预算

↗

Cursor pstack · 工作技能 · setup-pstack

用于初始化或调整 pstack 的模型分工及推理预算。确认当前可用模型，按角色写入常驻规则，并可建议补建项目验证技能。

 Skill

把任务提示词深化

↗

Cursor pstack · 工作技能 · sharpen

用于发送任务前提高提示词的专业深度。补出专家方法、原始材料、具体工具和独立验证依据，再重写提示词，不直接执行任务。

 Skill

记录可审计决策轨迹

↗

Cursor pstack · 工作技能 · show-me-your-work

用于长时间、无人值守或多阶段工作。用单一 TSV 记录选择、理由、证据与结果，结束时对照对话审计，并安排跨模型检查风险。

 Skill

验证状态模型并绘图

↗

Cursor pstack · 工作技能 · statechart

用于理解产品流程、协议或服务的状态变化。检查 TLA+ 模型，绘制 Mermaid 状态图，并用读者语言给出违反规则状态的最短路径。

 Skill

并行分工汇总覆盖

↗

Cursor pstack · 工作技能 · swarm

用于分片检查、探索或多个执行者竞赛。预先声明完成条件和竞赛规则，给工作者独立输出位置，再汇总结果、证据和覆盖缺口。

 Skill

先写失败测试再修复

↗

Cursor pstack · 工作技能 · tdd

用于明确要求 TDD 或有便宜清晰本地测试路径的缺陷。先证明回归检查因目标问题失败，再做最小修复并验证通过；不强行为昂贵场景造测试。

 Skill

把原理与缘由讲明白

↗

Cursor pstack · 工作技能 · teach

用于真正理解某个改动或子系统。调用 how、why 研究机制和设计动因，再按读者需要用白话分层解释，复杂关系逐步配图。

 Skill

按技术文档标准写作

↗

Cursor pstack · 工作技能 · technical-writing

用于文档、RFC、README、PR 描述和提交信息。先区分教程、操作指南、参考或解释，再应用清楚直接、低歧义的技术写作规则。

 Skill

约束类型脚本代码质量

↗

Cursor pstack · 工作技能 · typescript-best-practices

用于阅读或修改 TypeScript 文件。优先判别联合、品牌类型、边界 schema 和穷尽检查，减少 any 与断言，并要求真实测试和结构化日志。

 Skill

去除写作中的机器腔

↗

Cursor pstack · 工作技能 · unslop

用于清理任何文字中的 AI 写作痕迹。删空话、夸饰、抽象隐喻和模板句式，改成具体、主动、自然且保留原意的表达。

 Skill

追溯设计缘由与证据

↗

Cursor pstack · 工作技能 · why

用于追问设计选择、回归、事故或阈值来源。以代码与提交为锚点并行查询可用证据来源，区分事实、合理推断、竞争解释和未知项。
