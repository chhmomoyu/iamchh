Windows 置顶透明悬浮输入框（tkinter 提示词）

笔记可复用提示词，不是已完成的软件

要点

这是一条可复用的提示词，不是已经完成的软件。

  • 窗口置顶，并且无边框。
  • 背景使用抠色键 #010203，加上 -transparentcolor。
  • 隐藏一个 2×2 的 Entry，用来接收输入法。
  • 字和光标画在 Canvas 上。

结论

点击输入区时，把焦点交给隐藏的 Entry。按下回车，把文字交出去。

提示词

做一个 Windows 上的置顶、无边框悬浮输入框，用 Python tkinter。这是提示词，不是已经完成的软件。

窗口置顶，无边框。
背景使用抠色键 #010203，并设置 -transparentcolor，让这个颜色透明。
放一个 2×2 的隐藏 Entry，用来接收输入法。
字和光标画在 Canvas 上，不直接把 Entry 画出来。
点击输入区时，把焦点交给这个隐藏 Entry。
按下回车，把 Entry 里的文字交出去。
