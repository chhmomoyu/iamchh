Verification Skill：信任来自可执行验证

文章阅读笔记

要点

Feature Map 记下产品怎么跑、怎么用。可复用的 CLI 负责把东西跑起来，并收集证据。纠正优先靠优质代码库，以及 lint 和 CI。

结论

扩展 Agent 产能的前提，是能验证交付物，而不是多派活。
