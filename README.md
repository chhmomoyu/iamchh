# iamchh.com

iamchh 的个人网站。纯静态 HTML / CSS / JS，不需要打包。由 GitHub Pages 从本仓库根目录发布，自定义域名为 iamchh.com。对外品牌名只用 iamchh。

## 本地打开

用浏览器直接打开仓库根目录的 `index.html`。

中文字体通过 Google Fonts 加载。离线打开时会回退到系统黑体 / 宋体；英文大标题仍使用仓库里的 Cormorant Garamond。

## 页面

- `index.html` 首页
- `about.html` 关于（方向与联系方式，不使用真实姓名）
- `works.html` 作品集（目前没有可公开的作品）
- `work.html` 旧作品链接的回退页
- `blog.html` 博客
- `notes/browser-hand.html` 浏览器手夹
- `notes/tla-plus.html` 分支状态与 TLA+
- `notes/overlay-input.html` Windows 置顶透明悬浮输入框
- `notes/feature-pipeline.html` 两天到半天：用流水线把策划案落到能点、能通协议
- `post.html` 旧文章链接的回退页
- `collection.html` 收藏：7 篇阅读笔记，以及 58 条 Cursor pstack Skill
- `notes/` 里其余页面是这 7 篇阅读笔记
